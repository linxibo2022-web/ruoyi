# /dev - 开发新功能

用于标准业务功能的双模式生成：直接实现，或先生成配置再由用户微调。

## 必做步骤

1. 收集功能名称、所属模块和生成模式；先检查现有业务实现，避免重复开发。
2. 涉及数据库时读取 `database-ops`；代码实现遵循 `crud-development`，页面实现分别读取 `ui-pc` 或 `ui-mobile`。
3. 仅在用户确认方案后执行会创建表、字典或菜单的操作；不擅自修改生产数据。
4. 完成后运行受影响模块的最小验证并报告结果。

完整的字段推断、SQL、字典、菜单、主子表和树表模板位于 `.claude/commands/dev-references/full-guide.md`，仅在需要时读取。
