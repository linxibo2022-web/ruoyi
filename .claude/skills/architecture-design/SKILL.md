# 架构设计入口

1. 先确认需求、边界、租户与数据安全约束，再阅读同领域现有实现。
2. 保持本项目 Controller → Service → DAO → Mapper 分层和 `plus.ruoyi` 包结构；不引入 ruoyi-vue-plus 架构。
3. 优先复用现有技术与模块，明确影响范围、迁移路径和验证方式。
4. 技术栈、模块前缀、建表规则、案例和决策树按需读取 `references/full-guide.md`。

只读讨论不默认加载完整资料；涉及具体方案时再读取对应章节。
