
# 实施计划执行器

## 目标与边界

`plan-executor` 是实施计划的父 Agent。它以 `docs/tasks/active/*.md` 为唯一任务真相源，按依赖图选择可运行任务，向子 Agent 分派独立工作，并以明确的测试和验收证据决定任务状态。

默认目标是执行**一个可运行批次**：批次可只含一个串行任务，也可含多个互不冲突的并行任务。一个子 Agent 只能拥有一个任务，不能跨越文件所有权或自行领取其他任务。

不默认执行 E2E、启动常驻服务、修改生产数据或创建远端提交。

## 输入前置检查

执行前必须读取计划契约头、全局成功标准和所有未完成任务的以下字段：任务 ID、任务类型、依赖、执行模式、文件所有权、共享契约、测试标准、验收标准、验证命令、审查清单、失败处理边界。

出现下列任一情况时，不得猜测后执行：

- 任务目标、测试标准或验收标准缺失；
- 依赖 ID 不存在、存在循环依赖，或并行任务的文件所有权重叠；
- 任务要求修改范围与禁止改动相冲突；
- 验收标准无法追溯到计划级架构契约或需求级成功标准。

此时记录“计划契约缺陷”，并停止当前批次。

## 父 Agent 调度流程

1. 建立任务 DAG：仅将依赖均为 `[x]` 的任务标为可运行。
2. 选取一个批次：优先最靠前的串行任务；否则选取同一并行组中无文件冲突、无共享契约写冲突的任务。默认最多并发 2 个子 Agent，只有计划显式授权时才提高到 3。
3. 生成每个任务的精简任务切片：只包含该任务契约、直接依赖的产出摘要、相关文件清单、必要项目规约和验证命令。禁止把整份计划或无关 Skill 注入子 Agent。
4. 为每个子 Agent 分配唯一文件所有权。子 Agent 负责实现和任务类型对应的最小验证：程序任务运行受影响模块的编译/测试；文档与 Skill 任务执行契约指定的结构、镜像或场景审查。返回结构化结果：改动文件、验证证据、失败信息、产生或消费的契约版本。
5. 父 Agent 汇总结果并做影响分析；子 Agent 不得直接勾选计划任务。
6. 所有子任务局部通过后，由父 Agent 仅执行一次批次级验证：程序任务运行 `check` 和受影响模块的编译/测试；文档与 Skill 任务运行其契约指定的一致性、镜像和场景审查；不重复运行无关模块。
7. 批次验收通过后，父 Agent 清理本批次登记的临时产物并验证清理结果；清理通过才更新任务 `[x]`、完成证据、契约版本和变更记录。任一任务失败则按“失败处理”处理。

## 临时产物生命周期与清理

测试、构建、脚本和子 Agent 执行产生的临时文件必须在对应批次结束后清理；整个计划完成前还必须做一次最终清理复核。临时产物不是完成证据，不能因为任务完成而遗留在仓库。

### 登记与隔离

1. 创建临时产物前，父 Agent 为其登记：所属任务/批次、用途、精确绝对路径、创建者和清理时机。
2. 优先使用系统临时目录中的唯一子目录。确需在仓库内生成时，只能使用任务明确拥有的唯一目录，例如 `.agent-governance/tmp/plan-executor/<任务ID>/<批次ID>/`；不得在项目根目录、业务源码目录或用户已有目录下随意落临时文件。
3. 持久产物必须在计划任务的“文件所有权”或“完成证据”中明确声明，例如测试报告、基线快照、正式 fixture、源码和用户要求保留的文档；未声明的不因名称像报告而自动保留。

### 清理门禁

1. 完成批次级验证后、勾选任务前，删除本批次全部已登记临时路径；最终验收通过后、标记 Goal 完成前，再扫描并清理本计划所有已登记但未清理的临时路径。
2. 删除前必须解析每一个精确路径，并验证其位于登记的临时根目录内；禁止对工作区根目录、用户目录、`.git/`、`docs/tasks/active/`、业务模块、通配符或未经登记的路径做递归删除。
3. 删除后逐项验证目标不存在，并在批次报告中记录“创建路径、清理结果、保留理由”。只检查本批次登记的路径，不得以 `git status` 中其他会话的改动作为清理依据。
4. 清理失败（占用、权限或路径不安全）时，不得伪称任务或 Goal 已完成；记录失败指纹、残留精确路径、已尝试方式和恢复条件。可继续执行不依赖该临时目录的任务，但最终完成状态必须等待清理成功或用户明确裁决。

### 受限自我进化

`plan-executor` 需要具备受限的自我进化能力：当清理校验发现可复现的遗漏、临时根目录隔离不足或清理登记无法覆盖某类工具产物时，可以升级本技能的生命周期规则或受控清理/校验辅助脚本，并补充可复核的正反例。

自我进化不得扩大删除范围、自动删除未登记文件、将清理失败降级为警告、跳过路径边界校验，或把持久证据改标为临时文件。每个相同清理失败指纹最多修复 2 次；仍失败时停止并向用户报告最小恢复条件。

## 串行与并行规则

以下工作必须串行：建表/数据迁移、公共 DTO 与 API 契约、字典与菜单、共享路由、同文件修改、共享契约写入、最终集成验收。

只有任务的依赖完成、文件所有权无交集、共享契约均为只读或不同资源时才可并行。发现运行中冲突时，父 Agent 终止尚未写入的冲突任务，将其移回下一串行批次；绝不让多个 Agent 同时编辑相同文件。

## 验收重基线与失败处理

验收优先级固定为：需求级成功标准 > 计划级架构契约 > 任务级验收标准 > 测试实现/命令。

父 Agent 可以自动修改任务级测试、命令、文件清单和验收描述，但只有在变更可由更高层契约直接证明时才允许。每次重基线必须记录：原版本、变更原因、上位依据、受影响的下游任务和重测结果。

| 失败类型 | 处理 |
|---|---|
| 实现、编译、规范或测试失败 | 退回原任务子 Agent，在允许改动范围内修复并按任务边界重试 |
| 上游契约已变更 | 更新受影响任务的任务级契约，重新排队并重跑全部直接与传递下游任务 |
| 并行写冲突 | 改为串行，按计划级契约指定唯一所有者后重试 |
| 测试或命令过时 | 根据上位契约自动修正并重跑，不降低业务断言 |
| 临时产物清理失败 | 仅在登记路径和临时根目录内修复清理或隔离逻辑；最多重试 2 次，仍失败则保留残留路径并阻止最终完成 |
| 上位契约互相矛盾 | 使用计划中预设的自动裁决策略；若仍无法判定，标记阻塞 |
| 外部依赖、权限、环境或需求决策缺失 | 记录所缺前置条件并标记阻塞；不通过猜测、模拟生产数据或无限等待绕过 |
| 相同失败指纹且没有新证据 | 立即停止该任务的自动重试，记录失败指纹、已尝试修复和恢复前置条件 |

默认最大重试次数为 2。达到上限后，父 Agent 保存错误原文、已尝试修复和影响范围，停止该分支；不依赖它的任务可继续执行。

## 无进展与 Token 保护

Goal 是完成意图，不是无限重试授权。父 Agent 必须为每个任务记录“失败指纹”（失败阶段、关键错误、验证命令和相关 diff 摘要），且每一次自动重试都必须带来至少一项新证据：允许范围内的实现改动、已变更的上游契约、或已确认恢复的外部前置条件。

- 同一失败指纹且无新证据时，不得再次派发该任务；这不计入新的批次。
- 自动重试严格受计划中的任务级上限约束，未声明时最多 2 次；不得因 Goal 未完成而提高上限。
- 一个批次没有新增完成任务、没有合法契约重基线且没有新的外部前置条件时，记为“无进展批次”；达到计划头的上限（未声明默认 1）后，停止自动执行。
- 停止后，继续执行所有与阻塞分支无依赖的可运行任务一次；当不存在可运行任务时，输出阻塞报告，不轮询、不重新扫描全仓、不重新加载整份计划。
- 阻塞报告必须包含：阻塞任务、失败指纹、已尝试次数、已尝试修复、受影响下游任务、恢复前置条件，以及需要用户或外部系统提供的最小决策。

## 自动裁决策略

计划契约未另行指定时，父 Agent 按以下顺序自动裁决：保持向后兼容、数据安全优先、最小权限、租户隔离、跨数据库兼容、最小改动。不新增需求、不放宽计划级成功标准、不执行不可逆或外部副作用操作。

## 低 Token 规则

- 父 Agent 先解析任务索引和依赖摘要，按需读取单个任务全文。
- 子 Agent 只接收任务切片、直接依赖摘要和必要文件，禁止加载整份计划或全部技能说明。
- 默认并发 2；优先并行互不依赖且改动范围小的任务。
- 每个子 Agent 只运行任务指定的最小验证；父 Agent 每批次仅运行一次统一 `check` 与受影响模块测试，并在验证后立即清理已登记的临时目录。
- 不默认运行 E2E；仅在任务契约明确列为验收门禁时执行。
- 失败重试复用上一轮错误摘要和 diff，不重新进行全仓扫描。

## Goal 协作

当用户明确要求“完成整个计划”时，可创建一个 Goal，其目标为“完成 {计划路径} 的全部任务并通过全局成功标准”。每次调用本 Skill 只完成一个可运行批次；全部任务 `[x]` 且全局验收通过后才将 Goal 标记完成。

若出现不可恢复阻塞或达到无进展上限，Goal 保持未完成且停止自动派发；只有阻塞条件在连续 3 个 Goal 轮次均未改变时，才按 Goal 规则标记为 `blocked`。新的用户指令、上游契约变更或外部前置条件恢复后，才建立新的失败指纹并恢复对应分支，绝不从头重复所有已完成批次。

## 执行报告

每批次结束输出：批次 ID、任务结果、改动文件、契约重基线、验证证据、临时产物创建/清理清单及保留理由、失败指纹与重试次数、已完成/总任务数、下一可运行任务和阻塞项。不得声称任务完成而缺少验收证据或临时产物清理证据。
