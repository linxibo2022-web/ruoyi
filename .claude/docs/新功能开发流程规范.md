## ⚡ 第一步: 连接数据库 (必须执行)

### 为什么要连接数据库？

1. **查看现有表结构**: 了解项目已有的表设计规范
2. **检查表是否存在**: 避免重复创建表
3. **学习命名规范**: 字段命名、索引命名等
4. **验证 SQL 正确性**: 执行 SQL 前先验证

### 连接数据库的方法

```bash
# 方法1: 使用 MySQL 客户端
mysql -h 127.0.0.1 -P 3306 -u root -p

# 方法2: AI 询问用户数据库信息
# AI: "请提供数据库连接信息：主机、端口、用户名、密码、数据库名"
```

### 必须查询的信息

```sql
-- 1. 查看所有业务表
SHOW TABLES LIKE 'b_%';
SHOW TABLES LIKE 'm_%';

-- 2. 查看表结构示例 (学习字段命名)
SHOW CREATE TABLE b_ad;
SHOW CREATE TABLE b_bind;

-- 3. 查看最新的菜单ID (避免ID冲突)
SELECT MAX(menu_id) FROM sys_menu;
```

### 2.2 表设计规范清单

#### ✅ 命名规范

| 项目 | 规范 | 示例 |
|------|------|------|
| **表名** | 前缀 + 业务名称 | `b_ad` (基础业务), `m_goods` (商城) |
| **主键** | `id` | `id BIGINT(20) NOT NULL AUTO_INCREMENT` |
| **外键** | `关联表_id` | `user_id`, `goods_id` |
| **状态字段** | `status` | `status CHAR(1) DEFAULT '1'` |
| **删除标记** | `is_deleted` | `is_deleted CHAR(1) DEFAULT '0'` |

#### ✅ 必备字段 (继承自 TenantEntity)

```sql
CREATE TABLE b_example (
    id          BIGINT(20)   NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    tenant_id   VARCHAR(20)  DEFAULT '000000' COMMENT '租户ID',

    -- 业务字段...
    name        VARCHAR(100) NOT NULL COMMENT '名称',
    status      CHAR(1)      DEFAULT '1' COMMENT '状态 (0停用 1正常)',

    -- 审计字段 (必备)
    create_dept BIGINT(20)   DEFAULT NULL COMMENT '创建部门',
    create_by   BIGINT(20)   DEFAULT NULL COMMENT '创建人',
    create_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by   BIGINT(20)   DEFAULT NULL COMMENT '修改人',
    update_time DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    remark      VARCHAR(255) DEFAULT NULL COMMENT '备注',

    -- 逻辑删除 (必备)
    is_deleted  CHAR(1)      DEFAULT '0' COMMENT '是否删除',

    PRIMARY KEY (id)
) ENGINE=InnoDB COMMENT='示例表';
```

#### ✅ 索引设计

```sql
-- 主键索引 (必须)
PRIMARY KEY (id)

-- 唯一索引 (业务唯一字段)
UNIQUE KEY uk_code (code)

-- 普通索引 (频繁查询字段)
KEY idx_status (status)
KEY idx_create_time (create_time)

-- 复合索引
KEY idx_status_deleted (status, is_deleted)
```

### 3.2 菜单 SQL 生成规范

#### 菜单表结构

> 🔴 **注意**：字段名是 `is_external_link`（不是 `is_frame`）！框架约定 `'1'`=积极 `'0'`=消极。

```sql
-- 推荐使用带列名的 INSERT（参考 database-ops 技能 7.2/7.3 节）
INSERT INTO sys_menu VALUES (
    menu_id,        -- [menu_id] 菜单ID (唯一,建议从已有最大ID+10开始)
    'menu_name',    -- [menu_name] 菜单名称 (中文)
    parent_id,      -- [parent_id] 父菜单ID (一级目录为0,二级菜单为父菜单ID)
    order_num,      -- [order_num] 排序值 (同级菜单排序)
    'path',         -- [path] 路由地址 (前端路由, F按钮='#')
    'component',    -- [component] 组件路径 (M目录=NULL, F按钮='')
    NULL,           -- [query_param] 路由参数
    '0',            -- [is_external_link] 是否外链 (0=非外链 1=外链) ⚠️ 不是 is_frame！
    '1',            -- [is_cache] 是否缓存 (1=缓存 0=不缓存)
    'menu_type',    -- [menu_type] 菜单类型 (M目录 C菜单 F按钮)
    '1',            -- [visible] 显示状态 (1=显示 0=隐藏)
    '1',            -- [status] 启用状态 (1=正常 0=停用)
    'permission',   -- [perms] 权限标识符
    'icon',         -- [icon] 菜单图标 (F按钮='#')
    100,            -- [create_dept] 创建部门 (固定100)
    1,              -- [create_by] 创建人 (固定1)
    sysdate(),      -- [create_time] 创建时间
    NULL,           -- [update_by] 更新人
    NULL,           -- [update_time] 更新时间
    'remark'        -- [remark] 备注
);
```

**权限标识符模板**：

- 基础业务模块: `base:功能名:操作`

5. **DAO**: 实现 `buildQueryWrapper(Bo)` 方法

## 🎯 第七步: 开发业务逻辑

### 7.1 后端业务增强

在基础 CRUD 的基础上，根据需求添加业务逻辑：

```java
@Service
@RequiredArgsConstructor
public class FeedbackServiceImpl implements IFeedbackService {

    private final IFeedbackDao feedbackDao;

    // ✅ 重写保存前钩子 - 添加业务校验
    @Override
    protected void beforeSave(Feedback entity) {
        // 业务校验: 内容不能包含敏感词
        if (containsSensitiveWords(entity.getContent())) {
            throw ServiceException.of("反馈内容包含敏感词，请修改后重试");
        }

        // 默认值设置: 新反馈默认为待处理状态
        if (entity.getId() == null && entity.getStatus() == null) {
            entity.setStatus("0");  // 0=待处理
        }
    }

    // ✅ 重写删除前钩子 - 添加关联检查
    @Override
    protected void beforeDelete(Collection<Long> ids) {
        // 检查是否有正在处理的反馈
        List<Feedback> feedbacks = feedbackDao.listByIds(ids);
        boolean hasProcessing = feedbacks.stream()
            .anyMatch(f -> "1".equals(f.getStatus()));

        if (hasProcessing) {
            throw ServiceException.of("存在正在处理的反馈，无法删除");
        }
    }

    // ✅ 自定义业务方法
    @Override
    public boolean handleFeedback(Long id, String result) {
        Feedback feedback = feedbackDao.getById(id);
        if (feedback == null) {
            throw ServiceException.of("反馈不存在");
        }

        feedback.setStatus("1");  // 1=已处理
        feedback.setRemark(result);

        return feedbackDao.updateById(feedback);
    }
}
```

CREATE TABLE b_feedback (
    id          BIGINT(20)   NOT NULL COMMENT '反馈ID',  -- 雪花ID，不用 AUTO_INCREMENT
    tenant_id   VARCHAR(20)  DEFAULT '000000' COMMENT '租户ID',

    content     TEXT         NOT NULL COMMENT '反馈内容',

    images      VARCHAR(1000) DEFAULT NULL COMMENT '图片列表',

    handler_id  BIGINT(20)   DEFAULT NULL COMMENT '处理人ID',
    handle_time DATETIME     DEFAULT NULL COMMENT '处理时间',
    create_dept BIGINT(20)   DEFAULT NULL COMMENT '创建部门',
    create_by   BIGINT(20)   DEFAULT NULL COMMENT '创建人',
    create_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_by   BIGINT(20)   DEFAULT NULL COMMENT '修改人',
    update_time DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    remark      VARCHAR(255) DEFAULT NULL COMMENT '处理结果',
    is_deleted  CHAR(1)      DEFAULT '0' COMMENT '是否删除',
    PRIMARY KEY (id),
    KEY idx_user_id (user_id),
    KEY idx_status (status),
    KEY idx_create_time (create_time)
) ENGINE=InnoDB COMMENT='用户反馈表';
