## R<T> API响应封装

```java
// 成功响应
@GetMapping("/list")
public R<PageResult<UserVo>> list(UserBo bo, PageQuery pageQuery) {
    PageResult<UserVo> result = userService.page(bo, pageQuery);
    return R.ok(result);
}

// 成功响应，返回ID
@PostMapping
public R<Long> add(@Validated @RequestBody UserBo bo) {
    Long userId = userService.add(bo);
    return R.ok(userId);
}

// 成功响应，无数据
@PutMapping
public R<Void> update(@Validated @RequestBody UserBo bo) {
    userService.update(bo);
    return R.ok();
}

// 失败响应
@DeleteMapping("/{ids}")
public R<Void> remove(@PathVariable Long[] ids) {
    boolean success = userService.batchDelete(Arrays.asList(ids), true);
    return success ? R.ok() : R.fail("删除失败");
}
```

## PlusLambdaQuery 查询构建器

```java
// 基础查询方法
.eq(User::getStatus, "1")                           // 等于
.ne(User::getId, userId)                            // 不等于
.like(User::getUsername, "admin")                   // 模糊查询（仅用于 String 类型）
.likeCast(User::getId, "123")                       // 模糊查询（用于非 String 类型，跨数据库兼容）
.in(User::getId, Arrays.asList(1,2,3))             // IN查询
.between(User::getCreateTime, startTime, endTime)   // 范围查询

// 动态条件查询 无需进行非空判断
@Override
protected PlusLambdaQuery<User> boToQuery(UserBo bo) {
    return of()
        // 字符串条件
        .like(User::getUsername, bo.getUsername())
        .eq(User::getStatus, bo.getStatus())

        // 数值条件
        .eq(User::getDeptId, bo.getDeptId())
        .in(User::getPostIds, bo.getPostIds())

        // 时间范围条件
        .between(User::getCreateTime, bo.getStartTime(), bo.getEndTime())

        .orderByDesc(User::getCreateTime);
}

// 复杂查询
public List<UserVo> getComplexUsers(UserQueryBo bo) {
    return query()
        .select("u.*, d.dept_name")
        .from("sys_user u")
        .leftJoin("sys_dept d on u.dept_id = d.id")
        .where("u.deleted = 0")
        .and(StringUtils.isNotBlank(bo.getKeyword()),
             "u.username like concat('%', ?, '%')", bo.getKeyword())
        .orderBy("u.create_time desc")
        .listAs(UserVo.class);
}
```

### like vs likeCast 使用规范（跨数据库兼容）

> ⚠️ **PostgreSQL 不支持对非字符串类型使用 LIKE 操作符**，必须使用 `likeCast()`！

| 字段类型 | 使用方法 | 说明 |
|---------|---------|------|
| `String` | `like()` | 直接模糊匹配 |
| `Long`, `Integer`, `BigDecimal` | `likeCast()` | 自动类型转换 |
| `Date`, `LocalDateTime` | `likeCast()` | 自动类型转换 |
| 其他非字符串类型 | `likeCast()` | 自动类型转换 |

```java
// ✅ 正确：多字段模糊搜索（跨数据库兼容）
String searchValue = bo.getSearchValue();
if (StringUtils.isNotBlank(searchValue)) {
    lqw.and(w -> w
        .likeCast(User::getId, searchValue)           // Long → likeCast
        .or().like(User::getUsername, searchValue)    // String → like
        .or().like(User::getNickname, searchValue)    // String → like
        .or().likeCast(User::getDeptId, searchValue)  // Long → likeCast
        .or().likeCast(User::getCreateTime, searchValue) // Date → likeCast
    );
}

// ❌ 错误：对非字符串类型使用 like（PostgreSQL 报错：operator does not exist: bigint ~~ varchar）
lqw.and(w -> w
    .like(User::getId, searchValue)              // Long 不能用 like！
    .or().like(User::getCreateTime, searchValue) // Date 不能用 like！
);
```

**跨数据库实现原理**：
- MySQL: 隐式转换，无需特殊处理
- PostgreSQL: `CAST(column AS VARCHAR)`
- Oracle: `TO_CHAR(column)`
- SQL Server: `CAST(column AS NVARCHAR(MAX))`

## 完整业务服务示例

```java
@Service
public class UserServiceImpl extends BaseServiceImpl<UserMapper, User, UserBo, UserVo> implements IUserService {
    
    @Override
    protected PlusLambdaQuery<User> boToQuery(UserBo bo) {
        return of()
            .like(User::getUsername, bo.getUsername())
            .eq(User::getDeptId, bo.getDeptId())
            .between(User::getCreateTime, bo.getStartTime(), bo.getEndTime())
            .orderByDesc(User::getCreateTime);
    }
    
    @Override
    protected void beforeSave(User entity) {
        // 数据校验
        if (StringUtils.isBlank(entity.getUsername())) {
            throw new ServiceException("用户名不能为空");
        }
        
        // 数据标准化
        entity.setUsername(StringUtils.trim(entity.getUsername()));
        entity.setEmail(StringUtils.lowerCase(entity.getEmail()));
        
        // 唯一性校验
        boolean exists = exists(of()
            .eq(User::getUsername, entity.getUsername())
            .ne(ObjectUtil.isNotNull(entity.getId()), User::getId, entity.getId())
        );
        
        if (exists) {
            throw new ServiceException("用户名已存在");
        }
    }
    
    @Override
    protected void beforeDelete(Collection<Long> ids) {
        if (CollUtil.isEmpty(ids)) {
            return;
        }
        
        // 检查用户状态
        List<User> users = listByIds(ids);
        for (User user : users) {
            if ("ADMIN".equals(user.getUserType())) {
                throw new ServiceException("管理员账号不能删除");
            }
        }
    }
}
```

## 性能优化技巧

- 查询优化: 使用 `select()` 只查询需要的字段
- 条件优化: 动态条件避免无效查询
- 分页查询: 大数据量必须使用分页
- 存在性检查: 使用 `exists()` 而不是 `count() > 0`
