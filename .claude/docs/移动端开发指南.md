## 快速开始 - 核心开发规范

### 像素单位规范 ⭐⭐⭐
-   **常规CSS：必须使用 `rpx` 而不是 `px`**
-   **UnoCSS**: 直接使用数值，1 = 8rpx（如：`w-10` = 80rpx）
-   **样式优先级**: 与 wd UI 组件配合时如果不生效则可使用 `!` 确保生效，如 `mt-20rpx!`

### 样式开发规范

-   **优先级**: wd UI 组件 → UnoCSS → 自定义 CSS
-   **跨平台**: 特别注意微信小程序样式兼容性
-   **注释格式**: 使用 `/* 注释 */`，禁用 `//`
-   **背景处理**:
    -   透明背景: `custom-class="bg-transparent!"`
    -   渐变背景: `custom-style="background: linear-gradient(to bottom, #fc8a46 0%, #fff 100%) !important;"`

## 📋 移动端标准代码模板（基于真实广告模块）

### 1. API 定义（adApi.ts）

```typescript
// plus-uniapp-demo/src/api/app/home/adApi.ts
import type { AdQuery, AdVo } from './adTypes'

/**
 * 查询广告配置列表
 * @param query 查询参数
 * @returns {AdVo[]} 结果
 */
export const listAds = (query?: AdQuery): Result<AdVo[]> => {
  return http.get<AdVo[]>('/app/home/listAds', query)
}

/**
 * 获取广告详情
 * @param id 广告ID
 * @returns {AdVo} 结果
 */
export const getAd = (id: string | number): Result<AdVo> => {
  return http.get<AdVo>(`/app/home/getAd/${id}`)
}
```

**关键点**：
- ✅ 使用 `http.get<T>()` 泛型定义返回类型
- ✅ 参数使用 `?` 表示可选
- ✅ 路径参数用模板字符串 `\`/path/${id}\``
- ✅ 接口返回 `Result<T>` 类型，需配合 `[err, data]` 处理

---

### 2. 类型定义（adTypes.ts）

```typescript
// plus-uniapp-demo/src/api/app/home/adTypes.ts

/** 广告配置查询类型 */
export interface AdQuery extends PageQuery {
  /** 主键id */
  id?: string | number

  /** 广告名称 */
  adName?: string

  /** 广告类型 */
  adType?: string

  /** 状态 */
  status?: string
}

/** 广告配置视图类型 */
export interface AdVo {
  /** 主键id */
  id: string | number

  /** 广告名称 */
  adName: string

  /** 广告类型 */
  adType: string

  /** 广告图片 */
  img: string

  /** 跳转路径 */
  jumpPath: string

  /** 状态 */
  status: string

  /** 创建时间 */
  createTime: string
}
```

**关键点**：
- ✅ Query 类型继承 `PageQuery`（分页查询）
- ✅ 所有字段必须添加 JSDoc 注释 `/** 注释 */`
- ✅ ID 类型使用 `string | number`（兼容不同后端）
- ✅ 可选字段使用 `?`，必填字段不加 `?`

### 3. 页面使用（index.vue）

```vue
<template>
  <view class="min-h-screen bg-#f9f9f9">
    <!-- 导航栏：WD UI 组件优先 -->
    <wd-navbar title="广告列表" />

    <!-- 列表展示 -->
    <view class="px-4 pb-8 pt-4">
      <wd-cell-group title="广告列表">
        <wd-cell
          v-for="ad in adList"
          :key="ad.id"
          :title="ad.adName"
          :label="ad.description"
          is-link
          @click="handleAdClick(ad.id)"
        />
      </wd-cell-group>

      <!-- 空状态 -->
      <wd-status-tip v-if="!adList.length" image="search" tip="暂无广告数据" />
    </view>
  </view>
</template>

<script setup lang="ts">
import { listAds, type AdVo } from '@/api/app/home/adApi'
import { to } from '@/utils/to'

/** 广告列表 */
const adList = ref<AdVo[]>([])

/** 加载广告列表 - 使用 [err, data] 异步处理 */
const loadAdList = async () => {
  const [err, data] = await to(listAds({ status: '1' }))
  if (!err && data) {
    adList.value = data
  }
}

/** 处理广告点击 */
const handleAdClick = (id: string | number) => {
  uni.navigateTo({
    url: `/pages-sub/ad/detail?id=${id}`
  })
}

/** 分享功能 */
const { handleShareAppMessage, handleShareTimeline } = useShare()
defineExpose({
  onShareAppMessage: handleShareAppMessage,
  onShareTimeline: handleShareTimeline,
})

onMounted(() => {
  loadAdList()
})
</script>

<style lang="scss" scoped>
/* 注意：CSS注释必须用 /**/ 格式 */
</style>
```

**关键点**：
- ✅ 使用 WD UI 组件（`wd-navbar`、`wd-cell`）
- ✅ 使用 `to()` 工具处理异步错误：`[err, data] = await to(api())`
- ✅ 使用 UnoCSS 类名（`min-h-screen`、`bg-#f9f9f9`、`px-4`）
- ✅ 使用 `useShare()` composable 添加分享功能
- ✅ CSS 注释必须用 `/* */` 格式，不能用 `//`
- ✅ 类名使用 rpx 单位或 UnoCSS 数值（1 = 8rpx）

## ⭐ 工具类优先原则

### 异步错误处理（必须使用）

```typescript
import { to } from '@/utils/to'

// ❌ 错误：使用 try-catch
try {
  const data = await listAds()
} catch (err) {
  console.error(err)
}

// ✅ 正确：使用 to() 工具
const [err, data] = await to(listAds())
if (!err && data) {
  adList.value = data
}
```

### 常用工具类（plus-uniapp/src/utils/）

| 工具文件 | 主要功能 | 常用方法 |
|---------|---------|---------|
| **to.ts** | 异步错误处理 | `to(promise)` 返回 `[err, data]` |
| **string.ts** | 字符串处理 | `isEmpty()` `truncate()` `objectToQuery()` |
| **date.ts** | 日期处理 | `formatDate()` `parseDate()` `getRelativeTime()` |
| **boolean.ts** | 布尔转换 | `parseBoolean()` `isTruthy()` `toBooleanNum()` |
| **validators.ts** | 数据验证 | `isPhone()` `isEmail()` `isIdCard()` |
| **platform.ts** | 平台判断 | `isWeixin()` `isAlipay()` `isApp()` |
| **route.ts** | 路由跳转 | `navigateTo()` `redirectTo()` `switchTab()` |
| **cache.ts** | 本地存储 | `getStorage()` `setStorage()` `removeStorage()` |
| **function.ts** | 函数工具 | `debounce()` `throttle()` `once()` |

**使用原则**：
- ✅ 优先使用项目工具类
- ✅ 再考虑 uni-app API
- ❌ 禁止重复实现已有功能

## 🎯 Composables 使用（自动全局导入）

`plus-uniapp/src/composables/` 中的函数会自动全局导入，无需手动 import：

```typescript
// ❌ 不需要手动导入

// ✅ 直接使用
const { getDict } = useDict()
```
